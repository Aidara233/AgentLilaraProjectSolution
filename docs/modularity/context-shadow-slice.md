# D1 增量上下文影子图最小切片

本切片验证固定输入的纯渲染与图内同步传递，不切换生产路径，也不作为 D1 全部验收或 D5 拍前 IO 已成立的证据。

比较器勘察：CanonicalComparer 面向 SessionBrainRequest/ModelRequest，折叠消息边界且不比较频道状态；WireComparer 面向实际协议请求，允许部分协议差异为 notes。两者不能直接证明频道日期、游标和图片集合等价。本切片先逐字段比较消息 Role/Content/ContentParts 及频道状态，后续完整请求阶段再复用既有比较器。

范围：一条无图片增量消息，输入包含固定本地时间、发送者、原文、消息/回复平台 id、bot/mention 标志及上次渲染日期。mention 的端口与原始 CSV 精确匹配语义在拍前求得；日期转换使用宿主原 TimeUtil。所有输入都是值，不含宿主实例或查询句柄。

旧路径：独立创建 ChannelContextState，通过现有 ChannelContextService.FormatIncomingAsync 执行，假数据源提供固定 bot id。不得将此输出用于构造图节点或图输出。

图路径：测试专用纯节点通过 GraphInstance 求解。唯一激活源携带冻结输入，格式节点独立实现增量文本与日期变化计算，结果含消息文本和下一日期；采集汇块只在成功求解后取得结果。图节点 Evaluate 不调用旧渲染器、不执行数据库/文件/网络/媒体 IO，也不修改外部频道状态。

验收：完整文本（含Unicode、换行、特殊字符）、Role、null内容块、下一日期及旧状态中其他字段/图片集合不变；覆盖无时间、首日、同日、跨日、bot、端口mention、CSV精确mention和回复。连续消息分别用独立旧状态与图状态推进。负对照必须改变图结果或连线并使比较失败，证明对拍能发现差异。检查求值顺序和实际端口流，确认图并非仅包装已生成的旧输出。

不覆盖：历史、引用递归、图片/OCR就绪时序、游标落盘、系统时间行、真实模型协议和并发输入。后续必须扩大到独立拍前装载与状态提交，再决定 D5；当前不得据此启动 D2 全部内置路径切流。
